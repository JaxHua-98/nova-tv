# NOVA TV 原生试玩版状态

## 视觉

- 1920×1080 逻辑画布，等比适配当前屏幕。
- 左右安全边距 64px，顶部 40px。
- 流体渐变背景、玻璃卡片、半透明描边与柔和光效。
- 功能卡、最近观看、热门内容均完整显示在 16:9 画面内。
- 边缘卡片使用方向性缩放原点，不越过安全边距。

## 焦点

首页导航图为显式空间导航，不依赖默认 Tab 顺序。19 个目标包括：

- 4 个状态按钮；
- 搜索框；
- 4 个功能卡；
- 最近观看“查看全部”与 3 张卡片；
- 热门内容右箭头与 5 张海报。

焦点状态包含：

- 2dp 白色实心描边；
- 柔和外发光；
- 轻微放大；
- 弹簧式焦点过渡；
- Enter / DPAD_CENTER 确认；
- Back 逐区返回。

## 页面

- 首页：完整。
- 搜索：本地演示数据筛选、方向键导航、Enter 打开第一条。
- 详情：返回、播放占位、收藏切换。
- 电视直播：标准 M3U/TXT 解析、分组筛选、频道预览。
- 聚合片库：分类筛选、内容卡片、详情入口。
- 音乐：独立 MediaSessionService、四曲 Media3 播放队列、后台播放、进度、上一首/下一首、点选切歌与当前曲目同步高亮。
- 收藏与历史：双 Tab、进度展示、详情入口。
- 设置：内容源、浏览、播放、音乐、外观、关于。

## 已知边界

- 演示图来自 Unsplash，仅用于 UI 评审，正式发布前必须替换。
- 影视和直播播放器尚未接入真实源。
- 尚未在 Android TV 实机或电视模拟器上运行，原生画面和真实遥控器手感仍需下一轮验证。
- 当前没有交付 APK 或 AAB，符合本轮“先试用源码与原型”的要求。
- 音乐四曲队列分别使用不同的 24 秒原创合成试听音频，用于验证真实切歌、媒体会话和焦点联动；尚未接入第三方音乐源。
