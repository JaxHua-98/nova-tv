# NOVA TV · Android TV 交互试用版

这是 NOVA TV 的浏览器交互试用版，用于在不出 APK 的前提下评审首页视觉、子页面结构、遥控器焦点和 TVBox 内容源管理。Android TV 原生工程位于 `../android`，技术栈为 Kotlin + Jetpack Compose，不是 WebView 套壳。

## 打开方式

双击 `start-preview.cmd` 启动本地预览服务，然后访问：

```text
http://127.0.0.1:4178/
```

建议按 `F11` 全屏，并保持 16:9 窗口。不要直接双击 `index.html`：远程订阅、演示接口、图片代理和 HLS 代理依赖本地 Node 预览服务。

当前界面使用 1920×1080 逻辑画布，自动等比适配 1366×768、1080P 与 4K 屏幕。

## 已实现页面

- 首页：品牌、系统状态、时间天气、搜索、四功能入口、最近观看、热门内容；
- 搜索：本地演示数据与已启用在线片库联合搜索，支持远程条目详情和播放；
- 电视直播：从已启用内容源读取 M3U / TXT 播放列表，同名频道合并多条线路，支持分组筛选、频道选择和全屏 HLS 播放；
- 聚合片库：聚合已启用的苹果 CMS `type=3/4`、HTML 规则 `type=1` 和已登记的公开网页直连适配器，支持分类、卡片、详情和 HTTP(S) 片源播放；
- 音乐：独立音乐页、播放队列、播放/暂停、进度、上一首/下一首（本轮暂不扩展音乐源）；
- 收藏与历史：观看历史、我的收藏、进度展示与详情入口；
- 设置：内容源、浏览、播放、音乐、外观与关于。内容源管理只在设置中出现，首页不单独显示源卡片。

## 内容源管理

进入 `设置 → 内容源管理`，支持三种导入方式：

- **远程订阅**：输入 `http(s)` 地址，经本地受控代理拉取 JSON；
- **粘贴 JSON**：粘贴完整 TVBox 配置，适合调试；
- **本地文件**：选择 `.json` 或 `.txt` 配置。

已兼容的 TVBox 字段：

```text
sites / lives / parses / headers / flags / home
```

已支持的执行范围：

- 标准 TVBox A 方言；
- `tvbox-desktop/1` B 方言；
- 苹果 CMS `type=3/4` 的列表、搜索、详情和 `vod_play_url` 线路解析；
- HTML 规则 `type=1` 的基础列表、搜索、详情和播放链接提取；
- `厂长` / `csp_NewCzGuard` 的公开网页兼容直连：读取厂长资源公开列表、搜索结果、详情页和站点公开返回的 HLS 地址；该适配不执行也不绕过配置中的私有 Guard；
- 标准 M3U / TXT 直播列表、同名频道多线路合并、分组筛选；
- `headers` 会参与支持的请求链路；Cookie 等敏感 Header 在界面脱敏，预览代理不会默认透传 Cookie、Authorization 或 Host。

订阅会保存到浏览器 `localStorage`，刷新页面后仍会保留。可在内容源列表中启用、停用、同步或删除；停用后直播和片库会按当前启用集合重新聚合。删除内置演示源后，可在底部使用“恢复内置演示源”重新加入。

### 同步与运行检测的区别

“同步成功”只表示配置文件已下载、JSON 已解析并保存，不代表其中的站点已经能返回影视内容。每次同步后会继续进行运行检测：

- 设置页会显示“运行正常 / 部分可用 / 检测失败 / 需 Spider”；
- 兼容性报告会列出实际读取到的影视条目数、直播频道数和失败原因；
- 片库优先使用真实订阅中的可执行站点或公开网页直连适配器；只要存在非演示来源，内置演示源就不会覆盖真实结果；
- 如果订阅没有可执行影视站点，片库会明确显示“当前不是你的 TVBox 订阅内容”，不会再静默把演示数据当成订阅结果。

以测试中的 `fan` 配置为例：共解析出 49 个影视站点，其中 48 个仍依赖私有 `csp_*`、drpy JS 或其他 Spider/provider 运行时，浏览器预览版不会执行；`厂长 / csp_NewCzGuard` 已通过同名站点公开网页直连适配，可读取 24 个首页条目、搜索“流浪地球”，并从公开播放页解析真实 HLS。该配置的 6 个直播源中 5 个可访问，共解析出 2338 个频道；“牛播一”指向本机地址，被预览代理的内网访问保护拒绝。

TVBox 配置中的 `timeout` 默认按秒解释，预览版请求层会统一换算为毫秒，避免把 `timeout: 20` 误当成 20 毫秒。

## 不能执行或不会绕过的范围

- Spider `type=0` 可以被识别、展示在兼容性报告中，但预览版不会运行 jar/dex，也不执行 Android Spider 内核；
- `csp_*`、drpy JS、jar、dex 等 provider 依赖同样不能在当前浏览器预览版中执行；后续 Android 原生端需要接入受控的 TVBox/JS/Spider 兼容内核；
- 当前只登记了经过验证的公开网页兼容直连站点，不会根据站点名称猜测并执行其他第三方页面；公开页面或 HLS 地址变化时，适配器需要同步维护；
- `parses` 会识别并展示，但不会自动调用解析服务；
- 不实现虎牙、抖音房间号换取真实播放地址；
- 不绕过 DRM、付费、防盗链、签名、地区限制或平台登录限制；
- 导入的订阅是否可用，取决于订阅本身、网络环境、站点授权和当前是否有可访问的 HTTP(S) 片源；
- 预览版不会把第三方订阅内容伪装成已授权正片。

内置演示源是本地桩配置，用于验证链路：影视条目来自 `/api/demo/cms`，播放使用 W3C 公开测试 MP4；直播使用 Mux、Apple 等公开 HLS 测试信号。它们不代表真实频道或真实影视正片。导入自己的授权订阅后，实际可用性取决于该订阅。

## 遥控器 / 键盘操作

- 方向键：移动焦点；
- Enter：确认、播放/暂停、进入页面或打开详情；
- Esc / Backspace / GoBack：关闭详情或返回上一层；
- 在内容源列表中使用方向键切换订阅，当前项会自动滚入可视区域；
- 在设置页，左侧导航按右键进入当前设置项，按左键返回导航；
- 在片库详情中按播放按钮可验证 MP4/公开 HLS 播放、暂停、快进、快退与静音；桌面浏览器优先使用 HLS.js，Safari/电视原生 HLS 作为回退；
- 在直播页选择频道后，进入右侧播放按钮可打开全屏 HLS 播放器。

所有子页面使用显式电视焦点规则，不依赖浏览器默认 Tab 顺序。焦点态同时包含白色实线边框、外发光和轻微放大，不只通过颜色区分。

## 当前边界

- 本轮不生成、不交付 APK 或 AAB；
- 音乐模块保留现有原创合成试听音轨，音乐内容源和音乐搜索尚未接入；
- 影视与直播演示条目的名称、图片和进度仅用于 UI 评审；
- 演示图片来自 Unsplash，正式发布前必须替换为有明确授权的素材；
- 原生 Android TV 版的内容源持久化建议后续使用 DataStore/JSON，并接入 Media3、OkHttp、Jsoup 与可控代理策略，避免仓促引入 Room 迁移。
